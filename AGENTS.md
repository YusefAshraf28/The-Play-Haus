# The Playhaus Creative Arm

Read `brand-context.md` before any creative, campaign, content, media, event, PR, influencer, CRM, community, or production task.

Use the matching `skills/<role>/SKILL.md` for the requested role. If the request spans roles, use this sequence: market or consumer research → creative strategy → creative direction → production → quality control → performance analysis.

Maintain strict separation from MonoPlay. Use TBC for unapproved facts and do not invent outcomes, partnerships, claims, prices, or capabilities.
