# The Playhaus Creative Arm

A 360 creative-arm skill library for The Playhaus.

Each skill must use The Playhaus brand foundation and must not draw on MonoPlay strategy, campaigns, language, audience, services, or visual direction.

## Structure

- `brand-context.md`: The Playhaus source of truth
- `skills/<role>/SKILL.md`: role-specific workflows and guardrails

## Operating rule

Read `brand-context.md` before producing work. Use TBC where a fact has not been approved. Never invent claims, audiences, capabilities, results, prices, or partner details.
